# Future Features

SignalIQ is designed as a long-term engineering project that will continue evolving as I learn new technologies and explore new areas of cybersecurity, software engineering, cloud computing, and artificial intelligence.

Rather than treating each new technology as a separate project, my goal is to continuously expand SignalIQ by solving real engineering problems one feature at a time.

---

# Version 1 — Foundation (In Progress)

Build the core threat intelligence pipeline.

## Goals

- Collect vulnerabilities from the CISA Known Exploited Vulnerabilities (KEV) catalog
- Store threat intelligence in a normalized SQLite database
- Enrich vulnerabilities using the National Vulnerability Database (NVD)
- Document the system architecture and engineering decisions
- Build an initial Power BI dashboard

**Status:** In Progress

---

# Version 2 — Threat Context

# Long-Term Vision

SignalIQ is intended to become more than a vulnerability database.

The long-term goal is to build a platform that automatically collects, enriches, prioritizes, and presents threat intelligence in a way that helps analysts spend less time searching for information and more time making informed security decisions.

Every new technology I learn—whether it's cloud computing, backend development, machine learning, or AI—can become another feature that expands the platform while solving a real cybersecurity problem.
